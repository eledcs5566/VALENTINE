# RIYA'S FISH 🐠
A little world, just for you. A virtual goldfish aquarium that works as a website and installs like an app. No server needed.

## Put it online with GitHub Pages (free)
1. Upload all these files to a GitHub repository (top level, no folders).
2. Repository → Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
3. After a minute your site is at `https://YOUR-NAME.github.io/REPO-NAME/`.
4. On Android Chrome open it and choose **Install app**.

Feeding history and settings are saved on each device (in the browser), so they stay after closing the app.
